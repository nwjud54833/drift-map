Read the Consumer Impact, Not Just Line Formatting Noise

TRADITIONAL LINE DIFF (NOISY) 42 lines changed (key reordering) 
- "currency": "USD",
- "total_cents": 12900,
+ "total_cents": "12900",
+ "settlement_currency": "USD",
  "items": [
    { "sku": "DRIFT-01", "qty": 1 }
  ]

Standard git diffs treat key reorders and formatting whitespace identically to silent type coercions (12900 → "12900").

DRIFTMAP SEMANTIC DIAGNOSTIC WHY THIS BREAKS CONSUMERS
1. /data/total_cents · integer → string (RULE_TYPE_CHANGED)

Strictly typed mobile/Go/TypeScript deserializers expecting an IEEE-754 number or int64 will throw a runtime parse exception.

2. /data/currency · string → missing (RULE_REQUIRED_FIELD_REMOVED)

Present in 3/3 baseline payloads; missing in candidate. Renamed to /data/settlement_currency without backwards-compatible alias.

Transparent Boundaries

Engineering Scope & Known Limitations

DriftMap is built for fast, deterministic browser-local contract analysis with explicit engineering guardrails.

SPEC SUPPORT

OpenAPI 3.0 & Raw JSON

Supports raw JSON payload arrays/objects and OpenAPI 3.0.x JSON/YAML specs. Swagger 2.0 and GraphQL SDL require conversion first.

RENAME HEURISTICS

No Fuzzy Rename Guessing

Field renames (currency → settlement_currency) are deterministically reported as a removal + addition so breaking removals are never masked.

MEMORY CEILING

2.0 MB Document Limit

Enforces a 2.0 MB ceiling per document inside the browser IndexedDB (contract-atlas) store to guarantee 60fps UI responsiveness.

COMPATIBILITY RULES

Structural vs. Business Logic

Validates structural types, nullability, and presence frequency, not domain-level semantic invariants (e.g., ISO currency code validity).
