# Feedback form

Copy the questions below into your reply and answer in your own words. Short
answers are fine.

**Please do not include private API data.** No real tokens, keys, cookies,
customer records, or internal hostnames. Replace values with placeholders such
as `REDACTED` or `user@example.test`. If the output itself contains something
sensitive, delete those lines before sending.

---

1. Did the report catch a real change? (yes / no / unsure) and why

2. What did you do next? (fixed it / ignored it / asked a teammate / other)

3. Would you run it again before your next deploy? (yes / no) and why

4. Where did you get stuck, if anywhere?

5. Can we quote your answers? (yes / no / ask first)
