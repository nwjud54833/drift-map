I am building `driftmap-cli`, a small command-line tool that compares two JSON
responses from your own API and tells you what changed, and which of those
changes can break a client.

then run:

```sh
npx driftmap-cli@latest compare before.json after.json
```

That is the whole ask: one command, on one endpoint you already know well.
About five minutes.

you at all, that is worth knowing too.
